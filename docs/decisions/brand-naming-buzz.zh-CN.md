# 品牌命名：Buzz

决策日期：2026-10-02

状态：已接受

## 决定

产品展示品牌由 **BuzzHive** 改为 **Buzz**，作为 **teatak** 旗下的子产品。保留现有 Buzz 主题的图标与品牌资产，延续已有的视觉识别。

2026-10-03 开始执行改名：产品、仓库、Go 包、命令、Docker 镜像及环境变量统一使用 Buzz / buzz / BUZZ。

## 理由

- 更偏好 Buzz 这个简短、直接的名字。
- Buzz 带有活跃、忙碌和持续工作的联想，符合希望传达的产品感觉。
- 产品属于 teatak 体系内的子产品，可以接受使用常见词以及存在同名产品的情况，无需以名称绝对独有为前提。

## 已知重名与取舍

讨论中已识别以下同名或近似名称：

- [BuzzHive](https://buzzhive.ai/)
- [Block 的 buzz 仓库](https://github.com/block/buzz)
- [Hive 的 Buzz](https://hive.com/buzz/)

这些名称可能影响搜索可发现性，也可能带来客户混淆。已知这些情况后，仍接受使用 Buzz 的命名方向。

以上仅记录命名取舍，不代表已完成商标核查、获得相关权利，或确认任何域名可用。

## 影响与边界

- 运行入口为 `cmd/buzz`，仓库为 `teatak/buzz`，镜像为 `teatak/buzz`。
- 环境变量统一使用 `BUZZ_`；默认数据库和数据库用户为 `buzz`。
- 原部署需备份并迁移后再升级，见 [迁移说明](../migration-buzz.zh-CN.md)。不增加旧配置的运行时兼容分支。
- 图标图形保持不变；第三方重名资料和本决策的历史名称保持原样。

对外首次介绍时，可考虑使用「Buzz by teatak」帮助区分。这是表达建议，尚未作为强制品牌规范采纳。
